# `@odata-ui/angular` (Stub)

> **Status:** Explicit stub / sketch — not yet built or published.

`@odata-ui/core` is framework-agnostic and mounts into any DOM element inside a Shadow Root. Wrapping it in Angular requires only an `ElementRef` container and calling `mount()` / `unmount()` in `AfterViewInit` / `OnDestroy`.

See [`src/odata-ui.component.stub.ts`](./src/odata-ui.component.stub.ts) for a standalone component sketch you can copy directly into an Angular 17+ app today.
