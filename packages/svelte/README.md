# `@odata-ui/svelte` (Stub)

> **Status:** Explicit stub / sketch — not yet built or published.

`@odata-ui/core` is framework-agnostic and mounts into any DOM element inside a Shadow Root. Wrapping it in Svelte requires only a `bind:this` container and calling `mount()` / `unmount()` inside `$effect` (Svelte 5) or `onMount` (Svelte 4).

See [`src/ODataUI.svelte.stub`](./src/ODataUI.svelte.stub) for a sketch you can copy directly into a Svelte 5 app today.
